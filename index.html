Summary of What's Ready Now

1.  No more R-33 / Address overlap: Every section uses flex-shrink: 0, the
    barcode uses aspect-ratio + background: 'transparent', and Auto-Fit to
    sticker height ensures tall labels scale cleanly onto 1 page without
    squishing or colliding.
2.  Bottom space control: Adjust Footer Bottom Space (px) under Accordion 3 (3.
    Text Spacing...) or Inner Bottom Padding (mm) under Accordion 1 to control
    the exact gap below PROUDLY MADE IN INDIA.
3.  Label Price (MRP) vs Actual Sale Price: Edit any product to set both Actual
    Sale Price (used at checkout/POS) and Label Price / MRP (printed on the
    label as MRP: ₹4,500, toggleable in Accordion 4).
4.  Google Sheets Sync: If you use Google Sheets, open Master Settings → Copy
    Script, update your Apps Script, and deploy a New version so the new
    labelPrice column syncs too!
